Tree all-reduce

Every worker holds a local value (in practice, a whole vector of parameter updates). All-reduce leaves every worker holding the sum of all of them, so all workers can continue from the same shared parameters. With the workers arranged in a spanning tree, all-reduce is a reduce (partial sums flow up, one level per step, until the root has the total) followed by a broadcast (the total flows back down). This is the scheme used by Vowpal Wabbit's Hadoop-compatible AllReduce.

Compare ring all-reduce, which splits the vector into chunks so every link is busy at every step.
