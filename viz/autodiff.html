autodiff.py — reverse-mode automatic differentiation

A function is written as a Wengert list (a flattened computation graph): a sequence of assignments out = fn(inputs…). The forward pass runs the list top-to-bottom to compute every val[·]; the backward pass runs it in reverse, using each op's local derivatives to accumulate δ[·] ≡ df/d· — the gradient. Watch how δ for a variable is incremented once per outgoing edge (e.g. x1 feeds add twice).
