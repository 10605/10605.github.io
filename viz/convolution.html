Convolution — sliding a 3×3 edge filter over an MNIST digit

A filter (kernel) is a small grid of weights. It slides over the input image one pixel at a time (stride 1, no padding); at each position the output is the sum of element-wise products of the filter and the 3×3 patch of pixels under it. A 28×28 image therefore produces a 26×26 feature map. Each simple edge filter is a dark row (or column) of −1s next to a bright one of +1s, so it fires strongly positive where the image matches that pattern and negative where it matches the reverse. Output colour is scaled so the largest |value| in the feature map is fully saturated.
Each output is out[r,c] = Σi,j x[r+i, c+j] · w[i,j] for i, j ∈ {0,1,2}. Strictly speaking that is cross-correlation, since the filter is not flipped, but it is what deep-learning libraries (e.g. torch.nn.Conv2d) compute and call "convolution". A CNN learns the filter weights; these four hand-made edge detectors are the kind of filter that early convolutional layers typically end up learning.
