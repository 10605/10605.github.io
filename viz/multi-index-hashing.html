Multi-index hashing with MinHash bands

Goal: given q, find all q′ with sim(q,q′) > s0. Every string gets M MinHashes ki(q) = min(hi(w) for w in q), grouped into b bands of r rows (M = b·r), with one inverted index per band. q′ is a candidate if it matches q on all r hashes of any band, so Pr(q′ is missed) = (1 − sim(q,q′)r)b. Here each q is a cartoon character's name, and its words w are character 3-grams.

Algorithm

Build:
  for each q′ in the collection:
    k(q′) = (k1(q′), …, kM(q′)),  ki(q′) = min(hi(w) for w in q′)
    for z = 1, …, b:
      indexz[ k(z−1)r+1(q′), …, kzr(q′) ] += q′
Query q:
  recompute k(q)
  candidates = ∪z indexz[ k(z−1)r+1(q), …, kzr(q) ]
  optionally rescore: keep q′ with sim(q, q′) > s0

found: sim > s₀ and a candidate · missed: sim > s₀ but no band matched · extra: a candidate with sim ≤ s₀ (discarded by rescoring).

sim(q, q′) is the Jaccard similarity of the 3-gram sets (each name is lower-cased and padded with a space at both ends, shown as ␣). Hash functions hi are seeded 32-bit mixers, so Pr(ki(q) = ki(q′)) ≈ sim(q, q′). Increasing b adds bands but keeps the existing hash functions fixed, so you can watch candidates appear.
