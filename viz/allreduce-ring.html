Ring all-reduce

Each of n workers holds a vector, and all-reduce must leave every worker with the elementwise sum. The workers form a ring in which each one sends only to its successor. Each vector is cut into n chunks, and every worker sends one chunk at every step, so every link in the ring is busy all the time.

Scatter-reduce (n−1 steps): each worker passes a chunk to its successor, which adds it to its own copy of that chunk. The chunks travel around the ring picking up one more term per step, and afterwards each worker holds one chunk that is fully summed. All-gather (n−1 more steps): the finished chunks travel around the ring the same way, but now each receiver simply overwrites its copy.

At scatter-reduce step s = 1, …, n−1, worker i (A = 0, B = 1, …) sends chunk (s − 1 − i) mod n; at all-gather step s it sends chunk (s − 2 − i) mod n, starting with the chunk it finished. So each worker's chunk moves one place to the right per step. (The lecture slides use the mirror-image schedule, (i − s + 1) mod n, which moves left; either works, as long as the chunk a worker sends next is the one it just received.)
