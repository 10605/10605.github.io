Bayesian prediction-powered inference

We want to know P(H = 1): for instance, the fraction of a QA system's answers that human raters accept. Human labels are expensive, so we only have n of them. An autorater (say, a prompted LLM judge) is cheap, so we also have its label A on N ≫ n more examples. But the autorater is biased: it has its own false-positive and false-negative rates, so P(A = 1) ≠ P(H = 1). The data here are simulated, so both true values are known.

Prediction-powered inference (PPI) combines the two kinds of labels with the proxy estimand of Eq 1 in the paper, using the autorater's labels f(x) = A on both samples and the human labels y = H on the small one:

g = μ1 + μ2,    μ1 = 1⁄N Σj f(x̃j)  (autorater mean, unlabeled data),    μ2 = 1⁄n Σi (yi − f(xi))  (the rectifier, labeled data)

The rectifier cancels the autorater's bias, so E[g] = E[y]. But μ1 has small variance because N is large, and μ2 has small variance whenever the autorater usually agrees with the humans, so g can have a much tighter interval than the human labels alone.

How the PPI interval is computed: Monte Carlo integration

As in Figure 2 of the paper. In the Bayesian version, μ1 and μ2 are random variables with posteriors given the data, and because they are computed from different examples they are independent. μ1 is a proportion, so its posterior is Beta(m + ½, N − m + ½), where m is the number of autorater 1's in the unlabeled data (Jeffreys prior). μ2 is a mean, so its posterior is Gaussian, centered at the mean rectifier with the standard error s/√n as its width (a Student-t if n < 30). We draw T = 10,000 times from each, compute g = s1 + s2 for each pair, sort, and cut off α/2 of the draws at each end.

Each example's human label is H ~ Bernoulli(P(H=1)), and its autorater label is A = H, flipped with probability P(A=1 | H=0) or P(A=0 | H=1). Moving the probability sliders re-thresholds the same random draws, so the samples change smoothly; the buttons draw new ones. The Monte Carlo draws use a fixed seed for the same reason.

As in the paper, the classical interval is the Clopper–Pearson interval, and the posterior curves for proportions use a Jeffreys prior, Beta(½, ½). The autorater-only interval is a Jeffreys interval for P(A=1): narrow, but an interval for the wrong quantity.
