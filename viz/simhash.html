SimHash bitstrings for MSML course titles

Each course title is a sparse vector x whose features f are its tokens. Bit i of its signature is a random hyperplane test, LSH[i] = sum(x[f]·r[i,f] for f in x) > 0 ? 1 : 0, with r[i,f] ~ Normal(0,1). Two vectors at angle θ disagree on a bit with probability θ/π, so similar titles get codes with small Hamming distance. The vertical dividers split each n-bit code h into m substrings h(1),…,h(m) for multi-index hashing.

Each dot is one course h. A course is a multi-index-hashing candidate if some substring has Hamming(q(z), h(z)) < r/m. Every dot below the dashed line (Hamming < r) must be one: that is the pigeonhole claim. Click a dot to make it q.
Course titles are the core courses, electives and example special-topics courses on the CMU MSML curriculum page (ml.cmu.edu/academics/machine-learning-masters-curriculum, Sept 2026). Features are lower-cased word tokens with x[f] = 1. Each r[i,f] comes from a seeded hash of (i, f) (so nothing needs to be stored); with pooling, it is instead looked up in a shared pool of poolSize Normal(0,1) draws, as in Van Durme & Lall.
