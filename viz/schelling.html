Schelling's model of segregation

Agents of two groups, A and B, live on a grid with some empty cells. Each agent looks at its (up to) eight neighbors and is happy if at least a fraction τ of its occupied neighbors belong to its own group. In every round, each unhappy agent moves to an empty cell. Nobody wants to be in the majority, only not to be in too small a minority, yet even a mild preference like τ = 30% usually ends in a map where the typical agent's neighbors are 70–80% like itself: the collective outcome is much more extreme than any individual's preference.

One round

round(grid):
U ← the agents that are unhappy now, in random order
for each agent a in U:
if a is still unhappy (its neighbors may have moved):
pick an empty cell by the move rule (if there is none, a stays)
move a there; its old cell becomes empty
repeat rounds until nobody is unhappy, or nobody can move (or 200 rounds pass)

“Fraction alike” for an agent is (neighbors in its group) / (occupied neighbors), over the 8 surrounding cells (fewer at the edges unless they wrap). An agent with no neighbors counts as happy and is left out of the average. With the cells shuffled at random, the expected fraction alike is about the size of the agent's own group, 50% when the groups are equal; that is the starting point of every run.

The sweep uses the current grid size (up to 40), empty share, group share, move rule and edges, and the same random start as the map (so it changes with “New random start”), with one run of at most 200 rounds per step. Whether an agent is happy depends only on which fractions a/b (b ≤ 8 occupied neighbors) are at least τ, so with a fixed random start the outcome is constant between consecutive such fractions (ticks on the axis; the taller ones are multiples of 1/8). The panel runs once per step, so the curve is exact, and for grids up to 40 the step containing the current τ is exactly where the map ends up.

T. C. Schelling, Dynamic models of segregation, Journal of Mathematical Sociology 1 (1971); Micromotives and Macrobehavior (1978).
