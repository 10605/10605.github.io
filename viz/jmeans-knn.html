Approximate k-NN with a hierarchical J-means tree

Cluster the N points into J clusters, then run J-means again inside each cluster, down to depth d. To search for a query qx, find the centroid closest to qx among its J siblings at each level (O(dJ) distance computations), then scan only the points in that leaf (O(N/Jd)).     Algorithm

    Build(points, depth):
  if depth = 0: return a leaf holding points
  run J-means on points → centroids c1,…,cJ, clusters C1,…,CJ
  childi = Build(Ci, depth − 1)   for i = 1,…,J
Search(qx, k):
  node = root
  while node is not a leaf:                     O(J) per level, d levels
    i = argmini dist(qx, ci) over node's children
    node = childi
  return the k points x in node closest to qx   O(N/Jd)
    Distances are Euclidean. Each J-means run uses k-means++ initialization and up to 30 Lloyd iterations, seeded so the same settings give the same tree. A node with fewer than J points is not split further, so leaves can be uneven. The tree search is approximate because a true neighbor can sit just across a cell boundary; the exact k-NN column computes all N distances.
